# Aoki-AI-Director-Dashboard · AI 导演看板

**「双看板工业化闭环」标准工作台** ｜ Claude Code / Agent Skill

> **核心信条**：AI 不做盲盒抽卡，人只负责在看板上**定审美、给意见、做拍板**；剩下的分镜对齐、资产归档、MD5 去重提交、抽帧质检、局部补拍与 2 帧安全切镜剪辑，全部由工作台自动闭环。

---

## 它解决什么问题

| 常见制作痛点 | 传统做法的问题 | 本工作台的工程解法 |
|---|---|---|
| **网页改字和本地文件夹脱节** | HTML 改了提示词或换了参考图，硬盘目录还是旧文件 | **镜像资产收纳**：拖图直接写盘进 `02_分镜参考帧/XX_简写/`，网页图片数 = 文件夹文件数 |
| **删掉的废弃图还留在目录里** | 打包提交或人工取图时误把废弃图传给模型 | **安全归档 `_弃用/`**：网页点 `×` 删除后自动移入 `XX_简写/_弃用/`，防误传且可随时找回 |
| **多镜共用参考图，重复上传占满图位** | 每个镜头各自带图，整段提交时同一张图传 3~4 遍 | **存储全量 · 提交去重**：本地各镜目录各自配齐方便取用；打包提交前按 MD5 指纹自动去重并映射 `@图1~@图N` |
| **整片只有几个镜头有瑕疵，重做太贵** | 整段推翻重生成，连好镜头和原配音节奏一起毁掉 | **质检补拍看板 + 2 帧安全剪辑**：只把拍板要改的镜头进补拍看板（原帧作底帧）短片补拍，按起止时间点前后预留 1~2 帧安全余量**只切画面**覆盖原视频轨 |

## 全链路五步闭环

```
脚本定稿
  │
  ▼
[1] 拍前「可编辑分镜看板」+ 本地同步服务
  │   ├─ 每镜 10 字以内简写（例：Shot 04 · 中庭落地掀盖）
  │   ├─ 四段可编辑文本：🎬镜头内容简述 / 🖼️图片提示词 / 🎥详细视频提示词 / 🎵音效与BGM
  │   └─ 📋 一键复制整镜融合提示词（自动带上 @参考图）
  │
  ▼
[2] 镜像资产收纳（01_简写 ~ NN_简写 + _弃用/）
  │   ├─ 网页拖入/上传参考图 → 自动写盘进 `02_分镜参考帧/XX_简写/`
  │   ├─ 点 `×` 移除参考图 → 自动移入该镜 `XX_简写/_弃用/`（防误传、可找回）
  │   └─ Cmd+S 保存 → 同步更新 HTML 与 `storyboard_manifest.json`
  │
  ▼
[3] 存储按镜全量 · 提交按 MD5 自动去重
  │   ├─ 本地每镜文件夹各自配齐所需全部参考图（方便人眼/手动取用）
  │   └─ 整段/整片打包提交时，按文件 MD5 指纹自动去重并分配 `@图1 ~ @图N`
  │
  ▼
[4] 首轮成片下载 → AI 质检结果报告 → 导演拍板「补充镜头看板」
  │   ├─ 生成完整视频并自动下载到本地 `03_生成片段/`
  │   ├─ AI 自动抽帧对照原分镜，输出质检结果报告 + 精确记录每镜起止时间点/帧号
  │   └─ 导演拍板只改其中几个问题镜头 → 生成「补拍看板」（原视频截帧作底帧）并短片补拍
  │
  ▼
[5] 2 帧安全余量「只切画面」自动剪辑
      └─ 确认补拍视频无误后，按步骤[4]记录的时间点前后预留 1~2 帧安全余量，
         仅替换视频画面轨道，完整保留原片音频与节奏，输出 `04_剪辑成片/*_FINAL_2帧安全版.mp4`。
```

## 快速启动本地同步服务

```bash
python3 scripts/start_editable_dashboard.py \
  --html <你的分镜看板.html> \
  --refs-dir <项目/02_分镜参考帧> \
  --port 8788
```

服务启动后自动打开浏览器，支持以下接口与联动：

- `GET /`：加载可编辑分镜看板 HTML
- `GET /api/health`：返回当前绑定的 `refs_dir`、`html_path`、`manifest_path`
- `GET /refs/<path>`：实时预览硬盘参考图
- `POST /api/upload`：网页拖图/上传后直接写入 `02_分镜参考帧/XX_<简写>/`
- `POST /api/delete`：点击缩略图 `×` 后自动将文件移入 `XX_<简写>/_弃用/`
- `POST /api/save`：`Cmd+S` 保存时同步写回 HTML 与 `storyboard_manifest.json`
